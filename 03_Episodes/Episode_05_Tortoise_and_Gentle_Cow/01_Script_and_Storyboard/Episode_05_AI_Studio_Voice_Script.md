## 📌 Manual Generation Instructions:
1. Open [Google AI Studio Speech](https://aistudio.google.com/generate-speech) in Chrome (logged in with `akm.malda@gmail.com`).
2. Select Model: **`Gemini 3.8 Flash TTS`** (or **`Flash Lite TTS`**).
3. In **Speaker Settings**, select or search the specified voice name (e.g. `Enzo`, `Sola`, `Cleo`, etc.).
4. Copy the exact text from **Style Box** into the Style Instructions field.
5. Copy the exact Bengali text from **Speech Box** into the Speech text area.
6. Press **Run** (or `Ctrl + Enter`), wait for the audio waveform to appear, then click **Download**.
7. Rename the downloaded `.wav` file to the specified **Filename** and place it in:
   `03_Episodes/Episode_05_Tortoise_and_Gentle_Cow/02_Audio/Voice_WAVs_Full_Rewrite/`
