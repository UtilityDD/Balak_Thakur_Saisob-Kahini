# qa

Output of the Balak painted-look library (see [../PLAN.md](../PLAN.md)), one subfolder per phase:
`phase1_head/`, `phase2_cloth_hands/`, `phase3_light_finish/`, `phase4_acting/`, `phase5_pilot/`.
Each holds the phase's QA sheet stills, the current-vs-painted comparison and any short test clips.
Large MP4s are gitignored; keep stills and contact sheets here.
