# reviews

The director's review notes for the Balak painted-look library (see [../PLAN.md](../PLAN.md)), one dated file per
review, e.g. `2026-11-25_phase1_review.md`: what was shown (QA paths), what the director approved, what to change.
Decisions that set a rule also go into `01_Series_Bible/DIRECTOR_DECISIONS.md` the same day.
