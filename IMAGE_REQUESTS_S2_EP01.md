# Image requests — Param Bismoy S1 Ep01 (new plates)

Why: Scene 02's long exchange (Harnath's wife ↔ the villager) holds one pose per character for ~40 s, and the
Pagol's plate is painted mid-laugh, so his mouth can never close in lip-sync. New plates fix both.

## Rules for every image (lip-sync + continuity)

1. **Same style as the existing plates**: painted TV-anime / storybook illustration, clean dark ink outlines,
   soft flat colour, warm light. Upload the reference plate(s) listed with each request so faces and clothes match.
2. **Mouth CLOSED, relaxed** on every character who will speak (lips together; a slight smile is fine).
   The lip-sync tool opens the mouth on the words; it cannot close a painted-open mouth.
3. **Face large enough**: the speaking face at least ~180 px tall in a 1920×1080 frame; face not hidden by hands/veil.
4. **16:9, 1920×1080 or larger**, no text, no watermark, no borders.
5. Same costume colours: wife — white sari with red border, red bindi, veil over hair; speaking villager — grey hair,
   moustache, off-white dhoti and shawl (exactly as in `plate_2c_villager_dawn.jpg`); other villagers — see the cast table; Pagol — long wild black hair, beard, torn sack-cloth, rain-soaked.

Save each result to `remotion_studio/public/images/s2_ep01/<file name>` (or upload to the Drive folder under
`images/s2_ep01/`) and tell Claude; it will make the lip-sync clips and re-cut the scene with them.
